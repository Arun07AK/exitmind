# Pitch deck backgrounds

Background images for the evaluation-round deck (Google Slides, "Pied Piper – EXITMIND (evaluation round)"). Each image holds a slide's figures and labels; the slide's text sits on top as editable text boxes.

Screenshots come from the running app (offline mode) on 22 Nov 2026. Numbers quoted on the slides come from `data/design/architect.json`, `data/design/recommend.json`, `docs/verification/plan-benchmark.md` and the recorded Saturnalia run summarised in `docs/PROGRESS.md`.
